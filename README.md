## ⚡ What I build

Self-hosted, Docker-first tools with a clean UI and no tracking — the kind of software you can actually run on your own box and trust.

- 🧭 &nbsp;**TREK** — a collaborative travel planner: maps, budgets, packing lists, journals.
- 🎵 &nbsp;**Tune** — Discord Rich Presence for Apple Music on Windows, with synced lyrics.
- 🧩 &nbsp;A growing **plugin ecosystem** on top of TREK.
- 🔒 &nbsp;Everything ships as Docker, works offline where it can, and phones home to nobody.
