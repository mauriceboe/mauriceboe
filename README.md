# Hi, I'm Maurice 👋

Full-stack developer from **Rostock**, on the German Baltic coast. By day I build software at a mid-sized company; evenings and weekends I build the self-hosted tools I actually want to use — and run every one of them on my own homelab. On the side I'm doing a further-education programme, because I like getting better at this on purpose.

## 🚀 What I build

`with all my heart` **[TREK](https://github.com/liketrek/TREK)** — a self-hosted, collaborative travel planner: interactive maps, day-by-day itineraries, budgets, packing lists, travel journals, real-time sync, PWA, SSO and a full plugin system. The project I've poured the most of myself into.

And a handful of **self-hosted apps I run privately** — a finance planner, a recipe planner, a Kanban board — the ones only my homelab ever sees.
